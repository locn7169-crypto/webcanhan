📖 Hướng dẫn sử dụng & Kết nối Firebase Realtime Database

1. Cách kích hoạt chế độ Admin: Thêm #admin vào cuối đường dẫn trên thanh địa chỉ (ví dụ: .../firebase-editable-demo.html#admin) và nhấn Enter.

2. Kết nối cơ sở dữ liệu thật: Mở tệp HTML này bằng trình soạn thảo và điền thông tin dự án Firebase của bạn vào biến firebaseConfig trong thẻ <script>. 

// Quy tắc bảo mật Realtime Database khuyến nghị (tab Rules trong Firebase Console):
{
  "rules": {
    ".read": true,
    ".write": true // Hoặc "auth != null" khi có xác thực
  }
}
